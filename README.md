# タイムカード（スマホ用 PWA）

スマホのホーム画面から1タップで打刻できる、サーバー不要のタイムカードアプリ。
GitHub Pages に置くだけで動き、運用コストはゼロ。

## できること

- **打刻**: 出勤 / 退勤 / 休憩開始 / 休憩終了（状態に応じて押せるボタンだけが有効になる）
- **夜勤対応**: 22:00 出勤 → 翌 6:30 退勤 は、出勤した日の実績として集計
- **月次集計**: 出勤日数・実働合計・休憩合計。退勤打刻漏れは赤字で警告
- **打刻漏れの手修正**: 日時を指定して追加でき、「手入力」タグが残る
- **CSV 書き出し**: Excel でそのまま開ける BOM 付き UTF-8
- **複数スタッフ**: 1台の端末で切り替え可能
- **オフライン動作**: 圏外・機内モードでも打刻できる（Service Worker）

## 制限（先に把握しておくこと）

- **データはその端末のブラウザ内にのみ保存される**。端末間で同期せず、
  ブラウザのデータ削除・プライベートモード・機種変更で消える。
  → 月末など区切りごとに「設定 → バックアップ書き出し」で JSON を保存する運用が前提。
- 打刻時刻は**端末の時計**をそのまま使う。改ざん防止機能はないため、
  不正打刻の抑止が要件なら別の仕組み（サーバー側記録）が必要。
- GPS・顔認証・位置制限は入れていない。

## 端数処理について

日ごとの切り捨て（例: 毎日15分未満を切り捨て）は労働基準法上認められていません。
認められているのは、**1か月の合計時間について 30分未満を切り捨て・30分以上を切り上げる**
処理のみです（昭和63年3月14日 基発第150号）。

そのため設定の選択肢は「1分単位（端数処理しない）」と「月合計を30分単位で四捨五入」の
2つだけにしてあります。日別表示は常に1分単位の実績を出します。

## 使い方

### 1. 公開する

このリポジトリの `main` に push すると GitHub Actions が GitHub Pages に自動デプロイします。
初回のみ、GitHub の **Settings → Pages → Build and deployment → Source** を
**GitHub Actions** に設定してください。

公開URL: `https://<ユーザー名>.github.io/<リポジトリ名>/`

### 2. スマホのホーム画面に追加

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「アプリをインストール」

ホーム画面アイコンから起動すると、ブラウザのバーが消えて通常のアプリのように使えます。

### 3. 初期設定

「設定」タブでスタッフ名を追加 → 「打刻」タブで運用開始。

## ローカルで動かす

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`file://` で直接開くと Service Worker が動きません。必ず HTTP サーバー経由で開いてください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造（打刻 / 記録 / 設定の3タブ） |
| `js/store.js` | localStorage への保存。打刻は追記のみで消さない |
| `js/calc.js` | 打刻ログ → 勤務セッション → 日別・月別集計 |
| `js/app.js` | 画面描画とイベント処理、CSV / バックアップ書き出し |
| `sw.js` | オフライン用キャッシュ |

## 次の段階（必要になったら）

複数スタッフの記録を1か所に集めたい場合は、Google スプレッドシート + Apps Script を
バックエンドにする構成が最も安く済みます（追加費用なし）。
`js/store.js` の保存部分を差し替えるだけで移行できるよう、保存層は分離してあります。
